## Project Description

In this project, we built a console program called the Municipal Financial Management System (MFMS) using C. The system works by presenting the user with numbered menu options, and from there they can carry out different tasks. Four main areas are covered: staff records, department funding, vendor details, and municipal property. The goal is to give municipalities a straightforward digital tool instead of relying on paperwork.



## Compilation Instructions

Open a terminal in the project folder and run:

gcc -std=c99 -Wall main.c employees.c budget.c suppliers.c assets.c reports.c utils.c -o mfms

## How to Run depending on device

Mac / Linux:  ./mfms
Windows:      mfms.exe
